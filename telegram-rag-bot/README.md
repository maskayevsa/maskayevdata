# 🤖 Telegram-бот с гибридным AI-поиском (RAG + SQL + Ollama)

Локальный интеллектуальный помощник в Telegram на базе **aiogram 3**, **ChromaDB**, **SQLite** и локальных языковых моделей **Ollama**. Бот работает полностью автономно без передачи данных во внешние облачные сервисы.

## ✨ Возможности

Бот поддерживает два независимых режима работы с переключением через кнопки меню:

1. **👥 Справочник о сотрудниках (Гибридный поиск: SQL + Vector + LLM):**
   * Умная маршрутизация запросов: точный поиск контактов, должностей и телефонов в реляционной БД (`SQLite`) + семантический поиск по функциональным обязанностям в векторной БД (`ChromaDB`).
   * Автоматическая фильтрация по отделам и генерация связного ответа через локальную LLM.

2. **📄 Помощь в делопроизводстве (RAG по нормативным документам):**
   * Точный поиск и прямое цитирование конкретных пунктов по запросу (например, *«процитируй пункт 1.15»* или *«п. 5.1»*).
   * Семантический поиск по смыслу с обязательным указанием источника (название документа, номер, раздел и пункт).
   * Индексатор `dochromadb.py` для парсинга размеченных текстов с сохранением иерархии метаданных.

3. **🛡 Безопасность и администрирование:**
   * Контроль доступа по белому списку `ALLOWED_USER_IDS`.
   * Защита контента от пересылки (`protect_content=True`).
   * Подробное ежедневное логирование действий в папку `logs/` и автоматический перезапуск при сетевых сбоях.

## 📂 Структура проекта

* `tele-bot-v3.py` — основной модуль Telegram-бота, маршрутизация режимов и логирование.
* `assistant.py` — движок гибридного поиска по базе сотрудников (SQLite + ChromaDB + Ollama).
* `assistant_normative.py` — движок поиска и цитирования по нормативной базе (ChromaDB + Ollama).
* `dochromadb.py` — скрипт парсинга и векторизации нормативных документов.
* `sample_normative.txt` — пример разметки документа для индексации.
* `requirements.txt` — список зависимостей Python.

## 🚀 Установка и запуск

1. **Установите и запустите [Ollama](https://ollama.com), затем загрузите необходимые модели:**
   ```bash
   ollama pull nomic-embed-text
   ollama pull saiga-rag-custom
   ```
   *(При необходимости укажите имя вашей локальной LLM в переменной `LLM_MODEL` внутри `assistant.py` и `assistant_normative.py`).*

2. **Установите зависимости Python:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Подготовьте тестовую векторную базу нормативных документов:**
   ```bash
   python dochromadb.py
   ```

4. **Настройте конфигурацию бота в `tele-bot-v3.py`:**
   * Впишите токен от `@BotFather` в переменную `BOT_TOKEN`.
   * Укажите свой Telegram ID в списке `ALLOWED_USER_IDS`.

5. **Запустите бота:**
   ```bash
   python tele-bot-v3.py
   ```

# Maskayev Data

Личный репозиторий проектов, скриптов и инструментов на стыке аналитики данных, автоматизации и разработки.

## 👤 О себе

Меня зовут **Станислав Маскаев**.  
Кандидат экономических наук, экономист на железнодорожном транспорте, магистр менеджмента в строительстве.
20 лет в транспортной отрасли и 4 года в строительстве (РЖД). Специализируюсь на аналитике данных, автоматизации процессов, методологии управления ресурсами.

- 🧠 **Аналитика:** Python (Pandas, NumPy), SQL, Power BI.
- 🤖 **Автоматизация:** скриптинг, Telegram-боты, OCR, обработка аудио/видео.
- 🏗 **Управление:** методология, бюджетирование, управление проектами (PMI, Agile).

## 📦 Проекты

### 🤖 Telegram-бот с AI-поиском по нормативной базе
Интеграция с Ollama для семантического поиска по документам.  
[→ Подробнее](./telegram_bot_ollama)

### 📄 OCR-обработка документов
Распознавание текста с изображений, обезличивание персональных данных.  
[→ Подробнее](./ocr_pipeline)

### 🎙 Обработка аудио и видео
Декодирование, нормализация, преобразование речи в текст.

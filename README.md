## 📦 Проекты

### 🤖 Telegram-бот с AI-поиском по нормативной базе
Интеграция с Ollama для семантического поиска по документам.  
[→ Подробнее](./telegram-rag-bot/)

### 👁️ Glazok AI — Цифровой видеоглазок с машинным зрением
Автономная система видеонаблюдения на Python (YOLOv8, InsightFace, FastAPI, go2rtc): непрерывная запись RTSP в .mkv, детекция человека, определение направления движения (вход/выход) и распознавание лиц по векторной базе в реальном времени.  
[→ Подробнее](./glazok-ai/)

---

### 🧩 Модули и инструменты в разработке

- **📄 OCR-обработка документов** (`./ocr_pipeline`) — распознавание текста с изображений, обезличивание персональных данных *(планируется как расширение для Telegram-бота)*.
- **🎙 Обработка аудио и видео** (`./audio_video_processing`) — декодирование, нормализация, преобразование речи в текст *(планируется как расширение для Telegram-бота)*.
- **⚙️ Полезные скрипты** (`./scripts`) — автоматизация рутины: сравнение списков, генерация отчётов, парсинг данных.

> *Каждый готовый проект содержит собственную инструкцию по установке и использованию.*

# 👁️ Glazok AI — Цифровой видеоглазок с машинным зрением

Локальная автономная система видеонаблюдения, непрерывной записи и распознавания лиц в реальном времени на базе **Windows 10/11**, **Python 3.13**, **YOLOv8**, **InsightFace** и **FastAPI**.

## ✨ Основные возможности
- **Управление видеопотоками:** автоматический запуск, контроль зависаний и ротация логов стриминг-сервера [go2rtc](https://github.com/AlexxIT/go2rtc).
- **Непрерывная запись архива:** сохранение RTSP-потока в 5-минутные сегменты `.mkv` без перекодирования (`-c copy`) с автоматической очисткой старых записей по лимиту объёма (50 ГБ) и срока хранения (30 дней).
- **Компьютерное зрение на GPU (CUDA):**
  - Детекция человека в кадре (**YOLOv8**).
  - Трекинг траектории и определение направления движения (**вход / выход**).
  - Распознавание лиц по локальной векторной базе в SQLite (**InsightFace / ONNX Runtime**).
- **Веб-интерфейс (FastAPI, порт `8081`):**
  - Лента событий с фотографиями, фильтрацией и привязкой к видеоархиву.
  - Добавление и переименование людей с дообучением базы эмбеддингов в 1 клик.
  - Создание ручного снимка с камеры.
  - Фоновый «догон» (анализ пропущенных отрезков видеоархива).
  - Изолированная «песочница» для тестирования распознавания на выбранных видеофайлах.

## 📁 Структура проекта
```text
glazok-ai/
├── app/
│   ├── catchup.py         # Фоновый анализ архива и режим песочницы
│   ├── cv_engine.py       # Движок детекции YOLOv8 и распознавания лиц InsightFace
│   ├── cv_worker.py       # Онлайн-обработка RTSP-потока и трекинг движения
│   ├── database.py        # Работа с SQLite (события, профили, векторные слепки)
│   ├── recorder.py        # Запись RTSP в .mkv сегменты и автоочистка диска
│   ├── supervisor.py      # Главный менеджер процессов (go2rtc, запись, CV, веб)
│   ├── template.html      # Шаблон веб-интерфейса
│   └── web_app.py         # Сервер FastAPI и REST API
├── Go2RTC/
│   └── go2rtc.yaml.example # Шаблон конфигурации видеопотоков камеры
├── config.yaml            # Основные настройки путей, лимитов, GPU и порта
├── requirements.txt       # Список зависимостей Python

```

## 🚀 Установка и запуск (Windows)

### 1. Подготовка бинарных файлов go2rtc и FFmpeg
Система использует сервер ретрансляции потоков **go2rtc** (автор — [AlexxIT](https://github.com/AlexxIT/go2rtc)).
1. Скачайте актуальный релиз `go2rtc_win64.zip` со страницы [GitHub Releases go2rtc](https://github.com/AlexxIT/go2rtc/releases) и поместите `go2rtc.exe` в папку `Go2RTC\`.
2. Скачайте сборку **FFmpeg** для Windows (например, `ffmpeg-release-essentials.zip` с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)) и скопируйте `ffmpeg.exe` в ту же папку `Go2RTC\`.

### 2. Настройка видеопотоков камеры
1. В папке `Go2RTC\` скопируйте файл `go2rtc.yaml.example` и переименуйте копию в `go2rtc.yaml`.
2. Укажите в `go2rtc.yaml` реальный RTSP-адрес, логин, пароль вашей камеры и локальный IP-адрес ПК в секции `webrtc`.

### 3. Установка Python и зависимостей
Рекомендуется **Python 3.11–3.13** и видеокарта NVIDIA с поддержкой CUDA. Откройте командную строку (`cmd`) в корневой папке проекта и выполните:

```bat
python -m venv venv
venv\Scripts\activate
pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```
*(Примечание: при первом запуске весов нейросети YOLOv8 и модели InsightFace скачаются автоматически в папку `data\models\`.)*

### 4. Настройка конфигурации (`config.yaml`)
При необходимости отредактируйте параметры в `config.yaml`:
- `recorder.max_size_gb` и `max_days` — лимит объёма (по умолчанию `50` ГБ) и срока хранения архива (`30` дней).
- `hardware.gpu_id` — индекс видеокарты NVIDIA (`0` — основная карта, `1` — вторая дискретная карта).
- `web.port` — порт веб-интерфейса (по умолчанию `8081`).

### 5. Запуск
Запустите файл **`start_glazok.bat`** двойным кликом. После старта откройте в браузере:
`http://127.0.0.1:8081`
